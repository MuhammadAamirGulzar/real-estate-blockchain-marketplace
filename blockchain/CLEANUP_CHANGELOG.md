## Migration Guide

### If You Were Using `auth.js`

```javascript
// OLD (backend/middleware/auth.js)
import { authenticateToken } from "../middleware/auth.js";

// NEW (backend/middleware/authMiddleware.js)
import { authMiddleware } from "../middleware/authMiddleware.js";
// or
import authenticateToken from "../middleware/authMiddleware.js"; // default export
```

### If You Were Using `DeployContract.sh`

```bash
# OLD
./DeployContract.sh

# NEW
cd blockchain
./script/deploy-all.sh
```

### If You Were Using `deploy-all.ps1` (Windows)

```bash
# Option 1: Use Git Bash (recommended)
cd blockchain
./script/deploy-all.sh

# Option 2: Use WSL
wsl cd blockchain && ./script/deploy-all.sh
```

## Verification Steps After Cleanup

1. **Test Backend Startup**

   ```bash
   cd backend
   npm run dev
   # Should start without import errors
   ```

2. **Test Contract Deployment**

   ```bash
   cd blockchain
   forge build
   ./script/deploy-all.sh
   # Should deploy all 12 contracts including payment system
   ```

3. **Verify Tests Pass**

   ```bash
   cd blockchain
   forge test -vvv
   # All 12 contracts should have passing tests
   ```

4. **Run Deployment Verification**
   ```bash
   cd blockchain
   node scripts/verify-deployment.js --network=localhost
   # Should show all contracts deployed and configured
   ```
